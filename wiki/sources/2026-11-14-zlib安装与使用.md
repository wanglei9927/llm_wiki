# 2026-11-14-zlib安装与使用

> heartleo/zlib——Z-Library 开源命令行工具（Go，MIT）：搜索/下载电子书、推送 Kindle 与微信读书、内置 TUI 与 MCP server 可接入 AI Agent。本机已装 v0.0.14。

## 基本信息

- **来源**：GitHub heartleo/zlib README（原始副本：raw/notes/2026-11-14-zlib安装与使用.md）；官网 zlib.heartleo.dev
- **日期**：2026-11-14
- **本机版本**：v0.0.14（/usr/local/bin/zlib，官方 install.sh 经代理 127.0.0.1:7897 安装）

## 核心观点

1. **三形态合一（CLI + TUI + MCP）**：单二进制既提供脚本化子命令（search/download/history 等，`--json` 输出可直接给程序消费），也提供持久终端交互界面 `zlib tui`（`/` 命令面板 + vim 风格 j/k 键位），还能以 `zlib mcp` 起 stdio MCP server 供 AI Agent 调用——一个工具覆盖人用和 Agent 用两种场景。
2. **doctor 域名探测是核心卖点**：Z-Library 镜像域名频繁漂移，`zlib doctor` 自动探测当前网络可达域名，`zlib mirrors` 可信任自备镜像，`zlib config network` 配代理——直击国内访问 Z-Library 的最大痛点。
3. **国内特色功能：微信读书导入**：`zlib weread import book.epub` 扫码登录后把书直接导入微信读书书架（少见功能），Kindle 推送走 SMTP（`zlib kindle send`）。
4. **AI 集成设计有安全考量**：提供 Claude Code / Codex 插件与 MCP 双通道；`zlib mcp --read-only` 隐藏全部写操作（下载/删历史/推送）；README 明确建议用户自己先 `zlib login`，让密码留在本地不进 AI 对话。
5. **配额与账号前置**：需要 Z-Library 账号，免费账号有每日下载配额（`zlib profile` 查询）；登录失败时可将浏览器已有会话以 cookies 导入。
6. **安装方式多元且轻量**：brew / install.sh / winget / Releases 二进制，Go 单二进制零重依赖，符合低性能设备"预编译优先"选型原则。

## 实操内容保留

### 本机安装（2026-11-14 实际执行）

```bash
https_proxy=http://127.0.0.1:7897 http_proxy=http://127.0.0.1:7897 \
  sh -c 'curl -fsSL https://raw.githubusercontent.com/heartleo/zlib/main/install.sh | sh'
# 输出：Installing zlib v0.0.14 (linux/x86_64)... Installed to /usr/local/bin/zlib
zlib version   # zlib version v0.0.14
```

### 首次使用三步

```bash
zlib doctor                          # 探测可达镜像域名
zlib login --domain https://z-lib.gd # 用 doctor 结果中的域名登录（输入邮箱密码）
zlib tui                             # 进入终端交互界面
```

### 常用命令速查

```bash
zlib search "dune" --ext epub          # 搜索（--ext 过滤格式）
zlib search "dune" --ext epub --json --count 10   # 脚本化输出
zlib download "id:hash"                # 下载（id:hash 取自搜索结果完整 id）
zlib profile                           # 每日下载配额
zlib kindle send ./book.epub           # 推送 Kindle
zlib weread import ./book.epub         # 导入微信读书
zlib favorites / recommended / most-popular / history
```

### TUI 键位

| 键 | 动作 |
|----|------|
| `/` | 命令面板（search/favorites/history/profile/settings/themes） |
| `↑/↓` 或 `j/k` | 选书 |
| `←/→` | 翻页 |
| `Enter` | 确认下载 |
| `Ctrl+F` | 修改搜索条件与过滤 |
| `Esc` | 返回 |
| `/quit` | 退出 |

### MCP 注册

```bash
claude mcp add -s user zlib -- zlib mcp            # Claude Code
codex mcp add zlib -- zlib mcp                     # Codex
# 加 --read-only 隐藏下载/删历史/Kindle/WeRead 写操作
```
