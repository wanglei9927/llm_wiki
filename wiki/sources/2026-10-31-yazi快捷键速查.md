# 2026-10-31-yazi快捷键速查

## 核心观点

1. **键位覆盖 17 个分类**：基础操作、光标移动、目录导航、选择/可视模式、打开、复制剪切粘贴、删除新建重命名、搜索过滤、复制路径、排序、常用目录跳转、标签页、任务管理器、信息查看、输入框、确认框、组合速记。
2. **组合键采用"前缀键"机制**：`c`（复制路径信息）、`g`（跳转目录）、`,`（排序）、`m`（行显示模式）、`t`（标签页）都是"先按前缀键，再按第二键"的两段式按键，这是 vim 风格设计，避免了单键位不够用的问题。
3. **退出与帮助的双通道**：`q` 退出、`Q` 退出且不记录目录、`Ctrl+c` 关闭标签页（最后一个标签页时才真正退出）；`~` 或 `F1` 随时打开内置帮助，帮助菜单实时显示当前所有键位，是键位权威来源。
4. **删除有安全分层**：`d` 移入回收站（可用 `g` `t` 打开回收站找回），`D` 永久删除——文档特别标注"危险！"。
5. **搜索能力依赖外部工具链**：`s` 按文件名搜索（fd）、`S` 按内容搜索（ripgrep）、`z` 模糊跳转（fzf）、`Z` 历史目录跳转（zoxide）——这些功能可用与否取决于本机是否装齐 fd/ripgrep/fzf/zoxide（本机 2026-10-31 已全部装齐）。
6. **vim 风格贯穿所有输入框**：重命名/新建/搜索时的输入框也支持 `i/a` 插入模式、`v` 可视选择、`0/$` 行首尾、`u/Ctrl+r` 撤销重做、`↑↓` 历史记录。

## 实操内容保留

### 文件操作核心键位（原文表格摘录）

| 按键 | 功能 |
|------|------|
| `空格` | 选中/取消选中当前文件（并下移） |
| `y` / `x` | 复制 / 剪切选中文件 |
| `p` / `P` | 粘贴 / 强制粘贴（覆盖同名） |
| `d` / `D` | 移入回收站 / 永久删除 |
| `a` | 新建文件（以 `/` 结尾则新建目录） |
| `r` | 重命名（光标定位到扩展名前） |

### 路径复制组合（c 前缀）

| 按键 | 功能 |
|------|------|
| `c` `c` | 复制文件完整路径 |
| `c` `d` | 复制所在目录路径 |
| `c` `f` | 复制文件名 |
| `c` `n` | 复制不含扩展名的文件名 |

### 常用组合速记（原文）

```
日常浏览：j/k 移动 → l 进入 → h 返回 → o 打开
文件操作：空格选中 → y 复制 / x 剪切 → 移动到目标目录 → p 粘贴
删除文件：d 进回收站（g t 可找回）｜D 永久删除慎用
快速定位：z 模糊搜索最常用，g h 回家
```
