# 2026-10-31-vim-init安装配置记录

> skywind3000/vim-init（韦易笑的轻量级全中文注释 Vim 配置框架）在本机的完整安装事实记录：安装三步、非交互装插件踩坑、7 模块结构、10 个插件分组。

## 基本信息

- **来源**：本机安装记录（原始副本：raw/notes/2026-10-31-vim-init安装配置记录.md），项目官方 README（github.com/skywind3000/vim-init）
- **环境**：Vim 9.1（apt，补丁 1-2141）/ Ubuntu 26.04.1 / Surface Go 3
- **日期**：2026-10-31
- **结果**：43 个插件装齐（~/.vim/bundles/），配置加载验证通过

## 核心观点

1. **模块化是最大卖点**：配置拆为 init/ 下 7 个文件（basic/config/tabsize/plugins/style/keymaps），入口 init.vim 用自定义 LoadScript 命令按序加载——对比"几百行 vimrc 一把梭"的常见做法，增改定位清晰，且 init-basic.vim 保证无 +eval 的 tiny 模式也能用。
2. **插件按分组管理**：`g:bundle_group` 列表控制开关（basic/enhanced/tags/filetypes/textobj/airline/nerdtree/ale/echodoc/leaderf），想禁一组改列表即可，不用进代码注释；文件类型类插件全部 `{'for': ...}` 懒加载，不拖慢启动。
3. **vim-plug 安装路径非默认**：`plug#begin(get(g:, 'bundle_home', '~/.vim/bundles'))`——插件装在 `~/.vim/bundles/` 而非常见的 `plugged/`，排查"插件没装上"时别看错目录（本次就因此误判失败）。
4. **非交互装插件必须用伪终端**：`vim -es` 与 `vim -E -s` 两种 ex 模式跑 `PlugInstall --sync` 均异常（前者装 0 个、后者装 1 个即中断）；`script -qec 'vim -u ~/.vimrc -i NONE -c "PlugInstall --sync" -c "qa!"' /dev/null` 提供伪 TTY 后 43 个插件一次装齐——CI/无人值守场景的标准解法。
5. **YCM 是例外项**：配置含 YouCompleteMe 的完整默认设置（补全触发、文件类型白名单），但它不在 vim-plug 清单内，需手动编译安装，本机未装；语法检查由 ALE 承担（gcc/cppcheck/flake8/pylint 等，nice -n5 降优先级）。
6. **官方推荐 fork 维护**：把仓库 fork 到自己名下持续修改，更新时从上游合并——配置即资产的维护思路。

## 实操内容保留

### 安装三步（官方）

```bash
sudo apt install -y vim
mkdir -p ~/.vim && git clone --depth 1 https://github.com/skywind3000/vim-init.git ~/.vim/vim-init
# ~/.vimrc 只有一句话：
#   source ~/.vim/vim-init/init.vim
```

### 非交互插件安装（本机验证有效）

```bash
script -qec 'vim -u ~/.vimrc -i NONE -c "PlugInstall --sync" -c "qa!"' /dev/null
# 验证：ls ~/.vim/bundles | wc -l   → 43
# 加载无错验证：vim -es -u ~/.vimrc -i NONE -c "qa!"   → exit=0 无错误输出
```

### 高频键位（来自 init-plugins.vim 与 init-keymaps.vim 注释）

```
<leader><leader>f{char}  easymotion 全文快速移动
ALT+e                    choosewin 窗口选择（A/B/C 编号跳转）
ALT+= / ALT+-            expand-region 按分隔符扩大/缩小选区
CTRL+p / CTRL+n          LeaderF 文件模糊匹配 / 最近文件 MRU
ALT+p / ALT+m            LeaderF 函数列表 / 全局 tags 模糊匹配
<space>nn / <space>nt    NERDTree 打开 / 切换
:so %                    重载当前编辑的 .vim 配置文件
```

## 原文精彩摘录

> 这既是一份合理的轻量级配置，更是一份简明教程。……大部分都是针对 Vim 7 以前的版本，太过陈旧，对 8.0/8.1 以后的各种现代编辑器特征支持不足。模块化不够好，全部塞在一个几百行的 `vimrc` 文件里，各部分搅在一起，增改都比较麻烦。

> 最好 fork 一份到你自己的仓库，然后不断修改，把它修改成你自己的东西，平时要更新时到这里同步下上游仓库，然后自己合并一下即可。

> 既然是全中文注释，帮助主要看 init-keymaps.vim 和 init-plugins.vim 两个文件，每个点我都写满了注释了，也是未来你自己可能修改的最多的两个文件。
