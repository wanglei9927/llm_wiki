# ibus-libpinyin

> IBus 输入法框架下的智能拼音引擎，Ubuntu 中文输入的默认方案之一，本机通过用户词典机制定制了 296 条高频术语。

## 简介

ibus-libpinyin 是 IBus 输入法框架的智能拼音引擎，基于 libpinyin 库实现整句输入与智能预测，是 Ubuntu 自带的中文拼音输入方案（本机版本 1.16.5，Ubuntu 26.04.1 仓库自带）。相比 ibus-pinyin（已停止维护的旧引擎），它支持双拼、整句纠错、云拼音可选、以及**用户词典**——最后一点是本机定制的关键：通过导入用户词典，让专业术语（数据库、运维、开发领域）在候选列表中获得最高优先级，日常打字效率显著提升。

libpinyin 的核心词库以二进制形式存放在 `/usr/lib/x86_64-linux-gnu/libpinyin/data/`（.bin 词库文件 + bigram.db 二元模型），ibus-libpinyin 层的系统配置与 setup 界面源码则在 `/usr/share/ibus-libpinyin/`。

## 用户词典机制（本机核心用法）

### 导入入口

导入通过**图形界面**完成：运行 `ibus-setup-libpinyin` →「User Data」页 →「Import Dictionary」按钮。

实现细节（从本机源码推导，2026-10-31 验证）：按钮的回调函数 `__import_dictionary_cb` 位于 `/usr/share/ibus-libpinyin/setup/main2.py`（约 570 行），它并不直接解析文件，而是把选中的文件路径写入 gsettings 键 `import-dictionary`；引擎进程 `ibus-engine-libpinyin` 监听该键的变化，检测到新路径后由引擎侧完成实际解析与入库。这种"GUI 写配置、引擎执行"的解耦设计意味着：直接调用 GUI 是唯一官方入口，不能绕过它喂文件给引擎。

### 词典文件格式

纯文本，**每行一条**，字段以制表符 `\t` 分隔：

```
短语	pinyin	频率
```

- **短语**：目标词条，可以是 2~6 字的词组；
- **pinyin**：该词条的拼音，规范为**不带声调的连续小写字母**，音节间不分隔（如「数据库」→ `shujuku`，「负载均衡」→ `fuzaijunheng`）。依据：libpinyin 的 `pinyin_iterator_get_next_phrase(iter, &phrase, &pinyin, &count)` API 与引擎二进制内的格式串 `%s\t%s\t%d`（以及兼容的空格分隔形式 `%s %s %d`）；
- **频率**：整数，越高越优先。系统默认新词频率约 10，**用户导入词建议统一给 100**，确保自定义术语压过普通词库候选。

### 生效流程

导入完成后执行 `ibus restart` 重启 IBus 守护进程，新词条即进入候选。未重启前 GUI 可能显示已导入但实际打字不出现。

## 本机词典现状

- **规模**：296 条词条（2026-10-31 建档），原始文件 `~/文档/user_dictionary.txt`，知识库存档 `raw/notes/2026-10-31-ibus-libpinyin用户词典.txt`；
- **领域分布**：数据库操作（数据库、索引、事务、联表、主键、外键、字段、查询、插入、更新、删除）、数据运维（备份、恢复、迁移）、关联关系（关联、联表）等，与用户"数据库、API、服务器运维、AI、开发"的日常高频工作语境一致；
- **频率策略**：全量 100，保证术语在整句输入时优先出现。

## 已知边界与注意事项

- **带声调拼音未验证**：`shu4ju3ku4` 这类带声调形式是否被导入解析器接受，本机未实测。若不带声调格式导入失败，可尝试带声调版本；
- **词长边界**：libpinyin 对单条词组长度有上限（长句应拆词录入），超长词条可能被静默忽略；
- **导出无官方入口**：GUI 只有 Import 没有 Export，因此词典源文件要自行保存备份（本机 `~/文档/user_dictionary.txt` 即源文件，已同步存入知识库 raw/ 目录）；
- **与云拼音的关系**：用户词典优先级高于云候选，本地术语不受网络影响。

## 实用信息

- **安装**：Ubuntu 自带（ibus-libpinyin 包，1.16.5）；设置界面运行 `ibus-setup-libpinyin`。
- **基本用法**：GNOME 设置 → 键盘 → 输入源中添加"智能拼音"；日常 `Shift` 切换中英；用户词典按上文格式准备文件后经 GUI 导入、`ibus restart` 生效。
- **适用场景**：需要整句智能输入 + 自定义专业术语候选排序的中文拼音用户；术语密集型工作（数据库字段名、运维操作、API 词汇）尤其受益。
- **注意事项**：导入文件必须用真实制表符（编辑器里注意不要被空格替换）；批量造词时频率统一 100 最省心；源文件自行备份（无导出功能）。
