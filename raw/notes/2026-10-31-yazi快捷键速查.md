> 键位来源：官方默认配置（keymap-default.toml）
> 文档生成日期：2026-10-31
>
> 💡 任何时候按 `~` 或 `F1` 可打开 yazi 内置帮助（实时显示当前所有键位）
> 💡 启动方式：终端里输入 `y`（退出后终端自动跳转到最后浏览的目录）

## 基础操作

| 按键 | 功能 |
|------|------|
| `q` | 退出 yazi |
| `Q` | 退出（不记录当前目录） |
| `Esc` / `Ctrl+[` | 退出可视模式、清除选择、或关闭当前视图 |
| `Ctrl+c` | 关闭当前标签页（最后一个标签页则退出） |
| `Ctrl+z` | 挂起进程（`fg` 恢复） |
| `~` / `F1` | 打开帮助菜单 |

## 光标移动

| 按键 | 功能 |
|------|------|
| `j` / `↓` | 下一个文件 |
| `k` / `↑` | 上一个文件 |
| `g` `g` | 跳到顶部 |
| `G` / `End` | 跳到底部 |
| `Ctrl+u` | 上滚半页 |
| `Ctrl+d` | 下滚半页 |
| `Ctrl+b` / `PgUp` | 上滚一页 |
| `Ctrl+f` / `PgDn` | 下滚一页 |

## 目录导航

| 按键 | 功能 |
|------|------|
| `h` / `←` | 返回上级目录 |
| `l` / `→` | 进入目录 / 打开文件 |
| `H` | 后退（浏览历史） |
| `L` | 前进（浏览历史） |

## 选择文件 / 可视模式

| 按键 | 功能 |
|------|------|
| `空格` | 选中/取消选中当前文件（并下移） |
| `v` | 进入可视模式（连续选择） |
| `V` | 进入可视模式（反向取消选择） |
| `Ctrl+a` | 全选 |
| `Ctrl+r` | 反选全部 |

## 打开文件

| 按键 | 功能 |
|------|------|
| `o` / `Enter` | 打开选中文件 |
| `O` / `Shift+Enter` | 交互式打开（弹出应用选择菜单） |
| `Tab` | 查看文件详细信息（信息卡片模式） |

## 复制 / 剪切 / 粘贴 / 链接

| 按键 | 功能 |
|------|------|
| `y` | 复制（yank）选中文件 |
| `x` | 剪切选中文件 |
| `p` | 粘贴 |
| `P` | 强制粘贴（覆盖同名文件） |
| `Y` / `X` | 取消复制/剪切状态 |
| `-` | 为已复制的文件创建**绝对路径**软链接 |
| `_` | 为已复制的文件创建**相对路径**软链接 |
| `Ctrl+-` | 创建硬链接 |

## 删除 / 新建 / 重命名

| 按键 | 功能 |
|------|------|
| `d` | 移入回收站（trash） |
| `D` | **永久删除**（危险！） |
| `a` | 新建文件（以 `/` 结尾则新建目录） |
| `A` | 批量新建文件 |
| `r` | 重命名（光标定位到扩展名前） |

## 搜索与过滤

| 按键 | 功能 |
|------|------|
| `s` | 按文件名搜索（fd，递归子目录） |
| `S` | 按文件内容搜索（ripgrep） |
| `Ctrl+s` | 取消进行中的搜索 |
| `z` | 模糊跳转到任意文件/目录（fzf） |
| `Z` | 模糊跳转到历史目录（zoxide） |
| `f` | 过滤当前目录列表（实时过滤） |
| `/` | 向下查找文件名 |
| `?` | 向上查找文件名 |
| `n` | 下一个查找结果 |
| `N` | 上一个查找结果 |

## 隐藏文件与预览滚动

| 按键 | 功能 |
|------|------|
| `.` | 显示/隐藏 隐藏文件 |
| `J` | 预览窗口向下滚动 5 行 |
| `K` | 预览窗口向上滚动 5 行 |

## 复制路径信息（c 前缀）

先按 `c`，再按第二个键：

| 按键 | 功能 |
|------|------|
| `c` `c` | 复制文件完整路径 |
| `c` `C` | 复制文件 URL（file:// 形式） |
| `c` `d` | 复制所在目录路径 |
| `c` `D` | 复制所在目录 URL |
| `c` `f` | 复制文件名 |
| `c` `n` | 复制不含扩展名的文件名 |

## 排序（, 前缀）

先按 `,`，再按第二个键（小写正序，大写倒序）：

| 按键 | 功能 |
|------|------|
| `,` `a` / `,` `A` | 按字母排序 / 倒序 |
| `,` `n` / `,` `N` | 按自然排序（数字按大小）/ 倒序 |
| `,` `m` / `,` `M` | 按修改时间 / 倒序 |
| `,` `b` / `,` `B` | 按创建时间 / 倒序 |
| `,` `s` / `,` `S` | 按大小 / 倒序 |
| `,` `e` / `,` `E` | 按扩展名 / 倒序 |
| `,` `r` | 随机排序 |

## 跳转常用目录（g 前缀）

先按 `g`，再按第二个键：

| 按键 | 功能 |
|------|------|
| `g` `h` | 回到主目录（~） |
| `g` `c` | 跳到 ~/.config |
| `g` `d` | 跳到 ~/Downloads |
| `g` `t` | 打开回收站 |
| `g` `空格` | 交互式输入路径跳转 |
| `g` `f` | 跟随软链接指向的目录 |

## 标签页

| 按键 | 功能 |
|------|------|
| `t` `t` | 在当前目录新建标签页 |
| `t` `r` | 重命名当前标签页 |
| `1` ~ `9` | 切换到第 1~9 个标签页 |
| `[` / `]` | 上一个 / 下一个标签页 |
| `{` / `}` | 与上/下一个标签页交换位置 |

## Shell 命令与其他

| 按键 | 功能 |
|------|------|
| `;` | 运行 shell 命令（不阻塞界面） |
| `:` | 运行 shell 命令（阻塞直到完成，可看输出） |
| `w` | 打开任务管理器 |
| `,` `m` 系列中 `m` `s`/`m` `p`/`m` `m`/`m` `o`/`m` `n` | 列表行显示模式：大小/权限/修改时间/所有者/无 |

## 任务管理器（w 打开后）

| 按键 | 功能 |
|------|------|
| `j` / `k` | 上下移动 |
| `Enter` | 查看任务详情 |
| `x` | 取消选中任务 |
| `w` / `Esc` | 关闭任务管理器 |

## 信息查看模式（Tab 打开后）

| 按键 | 功能 |
|------|------|
| `j` / `k` | 上下滚动内容 |
| `h` / `l` | 切换到上一个/下一个文件 |
| `c` `c` | 复制当前单元格内容 |
| `Tab` / `Esc` | 关闭 |

## 输入框常用键

（重命名、新建、搜索等场景下的输入框，vim 风格）

| 按键 | 功能 |
|------|------|
| `Enter` | 确认提交 |
| `Esc` | 返回普通模式 / 取消 |
| `i` / `a` | 进入插入模式 / 追加模式 |
| `v` | 进入可视模式（选中文本） |
| `h` / `l` | 左右移动光标 |
| `0` / `$` | 行首 / 行尾 |
| `w` / `b` | 下一个 / 上一个单词 |
| `d` / `x` | 剪切选中文本 / 当前字符 |
| `p` / `P` | 粘贴到光标后 / 光标前 |
| `u` / `Ctrl+r` | 撤销 / 重做 |
| `Ctrl+u` / `Ctrl+k` | 删到行首 / 删到行尾 |
| `Ctrl+w` | 删除前一个单词 |
| `↑` / `↓` | 输入历史 |

## 确认对话框

| 按键 | 功能 |
|------|------|
| `y` / `Enter` | 确认 |
| `n` / `Esc` | 取消 |

### 常用组合速记

```
日常浏览：j/k 移动 → l 进入 → h 返回 → o 打开
文件操作：空格选中 → y 复制 / x 剪切 → 移动到目标目录 → p 粘贴
删除文件：d 进回收站（g t 可找回）｜D 永久删除慎用
快速定位：z 模糊搜索最常用，g h 回家
```
