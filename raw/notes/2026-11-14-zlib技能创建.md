## 核心铁律

1. **下载是写操作，先征得用户同意**——报候选清单让用户挑，确认后再下。
2. **下书前先查配额**：`zlib profile`；quota_remaining=0 时告知用户明日再来，不硬试。
3. **id 必须带 hash**：只传 `id:hash` 完整串，漏 hash 会下载失败。
4. **密码不进对话**：登录由用户本人终端执行；会话存本地，无需也不应索要凭据。

## 工作流

### 1. status - 状态检查

```bash
zlib version        # 版本
zlib profile        # 登录状态 + 每日配额余量
```

未登录报错 → 引导用户终端跑：`zlib doctor` 找可达域名 → `zlib login --domain <域名>`（交互输密码）。

### 2. search - 搜书（主用工作流）

```bash
zlib search "书名或作者" --json --count 10          # 基础搜索
zlib search "linux kernel" --ext epub --json        # 按格式过滤
zlib search "..." --year 2020-2025 --lang en --json # 年份/语言过滤
zlib search "..." --order year --json               # 排序
```

- **必须加 `--json`**（表格输出不利于解析与展示）
- 取结果中的 `id`（完整 id:hash）、`title`、`author(s)`、`extension`、`year`、`size`
- 候选展示：编号 + 书名 + 作者 + 格式/年份/大小，让用户选

### 3. download - 下载

```bash
zlib download "117575325:aa93ed"            # 下载到当前目录
zlib download "id:hash" --output ~/下载/    # 指定目录（以 --help 为准）
```

下载前：查配额 + 用户确认。完成后 `ls` 验证文件落地，报告实际路径。

### 4. kindle - 推送 Kindle

```bash
zlib kindle send ~/下载/book.epub
```

前置：需先配置 Kindle 邮箱 + SMTP（`zlib config kindle`，用户未配置时提示此项由用户完成）。

### 5. weread - 导入微信读书

```bash
zlib weread import ~/下载/book.epub
```

前置：微信读书扫码登录（首次需用户扫码）。

### 6. browse - 浏览

```bash
zlib favorites / recommended / most-popular / history   # 均可加 --json
```

## 故障排查

| 症状 | 处置 |
|------|------|
| `not logged in` | 用户终端执行 doctor → login（勿代做） |
| 域名连不上 | 重跑 `zlib doctor`；`zlib mirrors` 信任自定义域名 |
| 网络超时 | `zlib config network` 配代理（本机代理 127.0.0.1:7897） |
| 登录失败 | docs/troubleshooting.md：浏览器 cookies 导入方案 |
| 配额耗尽 | 明日自动重置；不绕过不硬试 |
| 更新 | `zlib update`（或重跑官方 install.sh） |
