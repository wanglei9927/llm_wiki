## 安装步骤（按官方 README）

```bash
# 1. 安装 vim
sudo apt install -y vim

# 2. 克隆配置到 ~/.vim/vim-init（官方建议 clone 到 ~/.vim 内）
mkdir -p ~/.vim
git clone --depth 1 https://github.com/skywind3000/vim-init.git ~/.vim/vim-init

# 3. 创建 ~/.vimrc，内容只有一句话：
source ~/.vim/vim-init/init.vim

# 4. 安装插件（交互方式：vim 内运行 :PlugInstall）
```

## 非交互安装插件的踩坑与解法

vim-plug 官方 CI 惯用的 ex 模式在本机失败：

```bash
# 失败方式 1：-es 模式 → exit=0 但 ~/.vim/bundles 为空
vim -es -u ~/.vimrc -i NONE -c "PlugInstall --sync" -c "qa!"

# 失败方式 2：-E -s 模式 → 只装出 1 个插件（vim-airline）后中断
vim -E -s -u ~/.vimrc -i NONE -c "PlugInstall --sync" -c "qa!" < /dev/null

# 成功方式：script 提供伪终端，vim-plug 的 TUI 渲染正常工作
script -qec 'vim -u ~/.vimrc -i NONE -c "PlugInstall --sync" -c "qa!"' /dev/null
```

最终 43 个插件目录全部装齐，`vim -es -u ~/.vimrc -c "qa!"` 加载验证无错误输出。

## 配置结构（init/ 下 7 个模块）

- init.vim：入口，设 runtimepath 并按序加载以下模块（LoadScript 命令）
- init-basic.vim：基础配置（保证 tiny 模式可用，无按键/样式定义）
- init-config.vim：ALT 键支持、功能键键盘码、备份、终端兼容
- init-tabsize.vim：制表符宽度/空格展开（个人差异大，独立成文件）
- init-plugins.vim：插件定义（vim-plug，分组管理）
- init-style.vim：色彩主题、高亮、状态栏
- init-keymaps.vim：快捷键定义

## 插件分组（g:bundle_group 默认全开）

默认组：basic / tags / enhanced / filetypes / textobj / airline / nerdtree / ale / echodoc / leaderf

- 无条件默认：vim-easymotion（leader+f 快速移动）、vim-dirvish（文件浏览器）、tabular（表格对齐）、vim-diff-enhanced
- basic：startify、colorschemes、vim-misc、signature、signify（git diff 符号栏）、errormarker、choosewin（ALT+e）、vim-preview、fugitive
- enhanced：expand-region（ALT+/− 扩缩选区）、fzf、vim-dict、FlyGrep、ctrlsf、delimitMate、gista
- tags：vim-gutentags + gutentags_plus（ctags/gtags 自动索引，数据集中 ~/.cache/tags，项目根用 .root 标志）
- textobj：vim-textobj-user/indent/syntax/function/parameter/python/uri 全家桶
- filetypes：ps1/lua/c++11-17/rust/orgmode/python 语法增强（按 filetype 懒加载）
- airline：状态栏（deus 主题，关闭 powerline 字体依赖）
- nerdtree：space+nn/no/nt 等键位，懒加载
- ale：异步语法检查（gcc/cppcheck/flake8/pylint/luac 等，nice 降优先级）
- leaderf：CtrlP 超级替代（Ctrl+p 文件、Ctrl+n MRU、ALT+p 函数列表、ALT+m 全局 tags）；无 python 时回退 ctrlp
- echodoc：底部函数参数提示（配合 YCM/deoplete）

YCM（YouCompleteMe）有默认配置但未列入 vim-plug 清单——需另行手动编译安装，本机未装。

## 关键路径

- 配置根：~/.vim/vim-init/
- 插件目录：~/.vim/bundles/（plug#begin(get(g:, 'bundle_home', '~/.vim/bundles'))，注意不是 plugged）
- gutentags 索引缓存：~/.cache/tags
- 日常维护：改单个 .vim 文件后 `:so %` 重载；官方建议 fork 后个性化修改，与上游合并更新
