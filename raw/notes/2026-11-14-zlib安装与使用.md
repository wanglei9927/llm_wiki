# zlib 安装与使用指南

> 原始素材 | 记录日期：2026-11-14
> 来源：GitHub 仓库 heartleo/zlib README（MIT 协议）+ 本机安装记录

## 项目概况

- **名称**：zlib（zlib-cli）——A command-line tool for Z-Library
- **地址**：https://github.com/heartleo/zlib（1.9k star / 137 fork，153 commits）
- **语言/协议**：Go 编写，MIT 协议
- **官网**：https://zlib.heartleo.dev/
- **定位**：给用户和 AI Agent 用的 Z-Library 命令行工具：搜索、下载、推送 Kindle / 微信读书，内置 TUI 与 MCP server
- **本机版本**：v0.0.14（2026-11-14 安装，linux/x86_64）

## 安装方式

- macOS / Linux Homebrew：`brew install heartleo/tap/zlib-cli`
- macOS / Linux 安装脚本（装 /usr/local/bin，可能要 sudo）：
  `curl -fsSL https://raw.githubusercontent.com/heartleo/zlib/main/install.sh | sh`
- Windows winget：`winget install --id heartleo.zlib --exact`
- 或从 Releases 下载二进制放 PATH

**本机实际安装**（2026-11-14）：走官方 install.sh，经代理 `127.0.0.1:7897`，安装到 `/usr/local/bin/zlib`，验证 `zlib version` 输出 v0.0.14。

## 快速开始（需要 Z-Library 账号）

```bash
zlib doctor                          # 找出当前网络可达的 Z-Library 镜像域名
zlib login --domain https://z-lib.gd # 用 doctor 结果中的域名登录（输邮箱密码）
zlib tui                             # 打开终端交互界面
```

TUI 内：`/` 打开命令列表（search/favorites/history/profile/settings/themes）；`↑/↓` 或 `j/k` 选书；`←/→` 翻页；`Enter` 确认下载；`Ctrl+F` 改搜索条件；`Esc` 返回；`/quit` 退出。登录状态本地保存，之后只需 `zlib tui`。下载默认当前目录，可在下载前另选目录。

浏览器已有会话可以 cookies 方式导入（登录失败时）。

## 命令清单

| 命令 | 作用 |
|------|------|
| `zlib search "dune" --ext epub` | 搜索，支持 `--json --count 10` 脚本化 |
| `zlib download "id:hash"` | 按结果的完整 id:hash 下载 |
| `zlib favorites` | 收藏夹 |
| `zlib recommended` | 推荐书 |
| `zlib most-popular` | 热门书 |
| `zlib history` | 下载历史 |
| `zlib profile` | 账号与每日下载配额 |
| `zlib kindle send ./book.epub` | 推送到 Kindle（SMTP 配置） |
| `zlib weread import ./book.epub` | 导入微信读书书架（扫码登录） |
| `zlib doctor` | 探测可用镜像域名 |
| `zlib mirrors` | 管理信任的镜像 |
| `zlib config` | 配置网络/下载/搜索格式/Kindle/WeRead |
| `zlib theme` | 配色主题 |
| `zlib mcp` | 启动 MCP server（stdio） |
| `zlib update` | 自更新 |

## AI Agent 集成

- Claude Code 插件：`/plugin marketplace add heartleo/zlib` → `/plugin install zlib@zlib-plugin-cc`
- Codex 插件：`codex plugin marketplace add heartleo/zlib` → `codex plugin add zlib@zlib`
- MCP server（需 zlib 在 PATH 且已登录）：
  - `claude mcp add -s user zlib -- zlib mcp`
  - `codex mcp add zlib -- zlib mcp`
- 加 `--read-only` 隐藏下载、删历史、Kindle、WeRead 等写操作
- README 建议：由用户自己先 `zlib login`，密码不进 AI 对话上下文

## 注意事项

- 需要 Z-Library 账号；免费账号有每日下载配额（`zlib profile` 查询）
- Z-Library 域名经常漂移，doctor + 自定义 mirrors 是主要兜底手段
- 支持代理（`zlib config network`）；可信任自己的镜像域名
- 登录凭据存本地；故障排查文档 docs/troubleshooting.md（含 cookie 导入登录）
