# AI 学习笔记 · 知识库

> 一个「**编译一次、持续维护**」的个人知识库。AI 把碎片素材（网页、推文、公众号、PDF……）整理成互相链接的 wiki 页面，而不是按时间堆积的笔记流。这份文档是给新读者的阅读指南。

---

## 这是什么

- **主题**：AI 学习笔记（DeepSeek 应用、AI 编程、Agent、工具链、设计、办公自动化……）
- **规模**：55 篇素材摘要 · 50 个实体页 · 7 个主题页 · 4 篇综合分析（2026-11 统计）
- **形态**：本地 Markdown + `[[双向链接]]`，用 Obsidian / VS Code / GitHub 都能读
- **核心理念**：知识**编译一次、持续维护**，而不是每次从头读原文重新推导。所以价值在「编译后的页面」（实体页/主题页），不在原始素材。

---

## 如何开始阅读

### 推荐路径（新人 15 分钟上手）

1. **先扫目录**：读 [index.md](index.md)，它是全库目录，一眼看清有哪些实体、主题、素材。
2. **看知识地图**：读 [wiki/overview.md](wiki/overview.md) 的「知识地图」一节，明白这个库覆盖哪几块。
3. **挑一个主题页**：从 7 个主题里选感兴趣的，主题页是「某个领域的知识体系」，是最佳入口。
4. **顺着 `[[双链]]` 跳**：主题页里的 `[[xxx]]` 指向实体页（具体工具/概念/人物），看到感兴趣的往下钻。
5. **需要出处时再看素材摘要**：`wiki/sources/` 的每篇摘要都带「原文精彩摘录」和「实操内容保留」，是最细颗粒度。
6. **收尾看综合分析**：`wiki/synthesis/` 有 4 篇跨素材深度报告，适合想「一条线打通」的人。

### 一句话原则

> **利用双向链接跳读，而不是线性翻阅。** 从「主题 → 实体」建骨架，从「实体 → 素材」追细节。

## 5 分钟极速版（只想了解个大概）

1. 打开 [wiki/overview.md](wiki/overview.md)，读「知识地图」那一段（10 行）。
2. 打开 [wiki/topics/工具集.md](wiki/topics/工具集.md)，扫一遍「记录过的工具」表格。
3. 对哪个工具/概念好奇，就点它的 `[[链接]]` 进去看实体页。
4. 看到底部「相关页面」，继续跳，直到满足。

## 维护说明（给作者本人 / AI，外人可跳过）

- 入库流程：素材 → 存 `raw/` → 写素材摘要 → 建/更新实体页与主题页 → 更新 `index.md` / `overview.md` / `log.md` → lint 校验。
- 命名铁律：`[[链接名]]` 必须与文件名（去 `.md`）完全一致。
- 区分实体 vs 主题：实体回答「它是什么」，主题回答「领域知识体系」，同名不得同时出现在两处。
- 质量基线：实体页 ≥1500 字、无占位文本、sources 字段回填；摘要页必含「实操内容保留」和「原文精彩摘录」。
