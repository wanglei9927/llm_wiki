## 一、生词（5 个）

### 1. library · /ˈlaɪbrəri/ · 名词
**释义**：库（代码库）；图书馆
- 英文例句：Requests is a simple, yet elegant, HTTP **library**.
- 中文例句：这个 Python **库** 被 400 万个仓库依赖。
- 记忆技巧：library 本义「图书馆」——代码的「库」也是把一堆写好的工具收在一起，随时取用。

### 2. elegant · /ˈelɪɡənt/ · 形容词
**释义**：优雅的、简洁漂亮的
- 英文例句：Requests is a simple, yet **elegant**, HTTP library.
- 中文例句：这个设计很**优雅**。
- 记忆技巧：和 elephant（大象）开头都是 ele——大象动作虽大却显得从容优雅，帮你记 elegant = 优雅。

### 3. available · /əˈveɪləbl/ · 形容词
**释义**：可用的、可获得的
- 英文例句：Requests is **available** on PyPI.
- 中文例句：这份文档现在**可**在官网**获取**。
- 记忆技巧：avail（有用）+ able（能）→「能用的」就是 available。文档里见到它就想到「可以拿到 / 可以用」。

### 4. download · /ˌdaʊnˈloʊd/ · 动词 / 名词
**释义**：下载
- 英文例句：Requests is one of the most **downloaded** Python packages today.
- 中文例句：请**下载**这个文件。
- 记忆技巧：down（向下）+ load（装载）→ 从网络「往下装到本地」= 下载。反义词 upload（上传）。

### 5. authentication · /ɔːˌθentɪˈkeɪʃn/ · 名词
**释义**：认证、身份验证
- 英文例句：Requests supports Basic & Digest **Authentication**.
- 中文例句：登录时需要**身份验证**。
- 记忆技巧：authentic（真实的）+ -ation（名词后缀）→ 证明「你是真的」= 认证。常见缩写 auth。

## 二、长难句拆解（2 句）

### 句 1
> Requests allows you to send HTTP/1.1 requests extremely easily.

- 主干：Requests allows you to send requests.（Requests 让你发送请求）
- 关键结构：**allow sb to do sth** = 允许某人做某事（文档里极常见）
- 修饰：extremely easily（极其容易地，修饰 send）
- 全句翻译：Requests 能让你极其轻松地发送 HTTP/1.1 请求。

### 句 2
> Requests is one of the most downloaded Python packages today, pulling in around 300M downloads/week.

- 主干：Requests is one of the most downloaded Python packages.（Requests 是下载量最大的 Python 包之一）
- 关键结构：**one of the most + 形容词 + 复数名词** = 「最……的……之一」
- 后半句：pulling in around 300M downloads/week —— 现在分词短语补充说明，相当于「每周带来约 3 亿次下载」
- 全句翻译：Requests 是当今下载量最大的 Python 包之一，每周约有 3 亿次下载。
