## 推文二：@meow2149 原文

DeepSeek Harness 团队提出了一个新的 Agent 架构：Super-agent。 目前大多数 Agent 都以独立会话运行，多个任务需要用户自己切换和管理。DeepSeek 希望改变这种模式，让一个 Agent 能够持续在线，同时推进多个任务。 核心采用 Router + Worker 双层架构： ▪︎ Router 负责接收消息、管理上下文和分配任务。 ▪︎ Worker 负责具体执行，多个任务可以并行处理，互不干扰。 ▪︎ 事件驱动：Agent 可以主动关注群聊、代码审查和 CI 结果，不必每次都等待用户下达指令。 ▪︎ 持续运行：通过云端状态管理和 Watchdog 机制，支持后台执行、异常监控与恢复。 初步实验中，Super-agent 的任务完成时间中位数为 12.4 分钟，P95 为 15.7 分钟，而传统单会话方案的 P95 为 29.5 分钟。 目前该架构仍处于探索阶段，官方已开源原型实现，并非正式产品。 我觉得这个方向很值得关注。未来的 Agent 或许不再需要用户管理一堆会话，而是由一个 Agent 统一协调任务，用户只需要关注进度和结果。
