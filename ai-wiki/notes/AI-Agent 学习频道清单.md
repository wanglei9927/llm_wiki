## 四、学习路径（推文建议 + 我的补充）

1. **完全新手**：Jeff Su（建立概念）→ Tina Huang（框架）→ Karpathy（补原理）
2. **想动手做**：Tina Huang → Cole Medin → Nate Herk，跟着项目做
3. **想做生意/自由职业**：Liam Ottley + Dave Ebbelaar
4. **想系统扎实**：Karpathy + Andrew Ng + IBM / Google Cloud 官方内容

补充：B 站资源基本是「搬运 + 中配/字幕」，能找到完整官方号的很少；如果英语吃力，可先用 B 站中配建立概念，再回 YouTube 看原版跟项目。
