## 六、如何保持更新

1. 安装/卸载任意 skill、插件或 agent 后运行：

   ```sh
   node E:/llm_wiki/scripts/refresh-installed-skills.mjs
   ```

2. 实时模式（推荐开机自启，见启动文件夹 `refresh-installed-skills.vbs`）：

   ```sh
   node E:/llm_wiki/scripts/refresh-installed-skills.mjs --watch
   ```

3. `--check` 用于巡检：文档过期时退出码为 1。
