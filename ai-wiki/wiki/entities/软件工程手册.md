# 软件工程手册

> 《The Software Engineering Handbook — A Judgment and Decision-Making Approach》（James C. Davis，第一版）是一本把软件工程讲成「受控变更的工程学科」的现代手册，核心主张是「工程判断可以被显式化、被学习、被练习」，并用统一范式把判断与测量连接起来。

## 它是什么

一本面向实践的软件工程手册（155 页 / 12 章），作者 James C. Davis 是 Purdue 的软件工程研究者，出自其「model-based agentic software engineering」项目。它与传统 SE 教材的最大区别：**不按「需求→设计→测试」的流程平铺，而是围绕「工程师要做什么判断、有哪些替代、后果如何区分、测量如何支撑」来组织**。副标题点明了方法论——Judgment（判断）与 Decision-Making（决策）。

全书的隐含命题是：**有后果的工程决策通常同时面对竞争的考量、不完整的知识、不完美的测量与不确定性**，所以书不提供算法，而是「指出什么值得关注、提供推理方式、积累能支撑可辩护决策的证据」。

## 核心定义与框架

**核心定义**：

> Software engineering is the engineering discipline of controlled change in software systems. It creates and evolves software while preserving sufficient control over the properties and consequences that matter.

**统一推理范式**（每章复用）：

```
Model → Property → Observation → Evidence → Judgment
模型  → 属性    → 观测       → 证据     → 判断
```

**关键区分**：

- **受控变更 ≠ 阻止变更**：工程要的是「保持足够控制」，确定什么该变、什么必须为真、需要什么证据、何时推翻早先决定。
- **指标是模型**：一个 metric 本质是「把关心的属性连接到可观测事物」的模型；测量本身不做决策，只让现实的一部分可被观测，供工程师对比「模型预期」与「实际发生」。

## 全书结构（12 章）

| 章节 | 主题 | 核心问题 |
|---|---|---|
| 1 | Controlled Change | 软件媒介的易变性为何需要工程控制 |
| 2 | Process | 如何安排工程工作（确定性/可变性/可分解性三维度选型） |
| 3 | Teamwork | 团队能力是涌现属性，协调如何被工程化 |
| 4 | Engineering Knowledge | 工程组织必须「记住」什么、如何表示 |
| 5 | Requirements | 什么结果值得成为工程承诺 |
| 6 | Specification | 承诺如何精确到足以约束可接受的实现 |
| 7 | Architecture | 如何组织系统让义务共存、变更不必一次想清全部 |
| 8 | Design | 架构约束下剩下的选择如何解决 |
| 9 | Validation | 什么证据能让人相信系统可接受 |
| 10 | Research and Development | 不确定性与探索型工作的工程 |
| 11 | Failure-Aware Engineering | 面向失败的工程 |

## GenAI 视角

本书把 GenAI 内建到决策模型里，而非当作外挂：

- **GenAI introduces substitutable capability**（GenAI 引入「可替代的能力」）——团队能力不再纯靠不可替代的人。
- **GenAI changes both sides of the equation**（GenAI 同时改变个体与团队能力的等式）。
- 呼应「技术只是移动瓶颈」：GenAI 让「写代码」变充裕后，工程约束会转移到别处（控制、协调、决策）。

## 不同素材中的观点

来自 [[软件工程手册（书）]]：

- 软件工程的「受控变更」定义，以及「受控 ≠ 阻止变更」的辨析。
- `Model → Property → Observation → Evidence → Judgment` 是全书通用推理范式。
- 「技术移动瓶颈」的历史类比（蒸汽机/集成电路）用于论证 GenAI 时代工程约束会转移。
- 12 章结构中，规格说明、架构、验证等被重新表述为「决策 + 证据」问题。

## 评价与注意

- **优点**：把「工程判断」从经验直觉提升为可学习、可练习的显式过程；结构统一（每章都有「Measurement for decision-making」）；GenAI 视角现代。
- **注意**：第一版、无算法/代码，适合建立 SE 心智模型而非当速查手册；英文原文，术语较密。
