# Protocol Explorer

> 一个「看着数据包跑」的交互式网络协议学习站：覆盖 14 个协议，每个包逐字节解码，带网络拓扑动画，支持 14 种语言（含简繁中文）；作者 Dilum Sanjaya，alpha 阶段，部署在 Vercel

## 简介

Protocol Explorer 想解决的是网络学习里最抽象的一环：协议是分层的、握手是时序的，光看文字和静态图很难建立直觉。它的做法是把一次真实的网络交互（比如访问一个 HTTPS 网站）做成动画——数据包在客户端与服务器之间移动，每一步发生了什么、包里每个字节是什么，都能点开看。

它覆盖从「域名怎么变成 IP」到「HTTPS 怎么加密」再到「邮件和 SSH 怎么工作」的完整链路，适合当网络协议的入门与复习材料。

## 核心能力

- **逐包动画**：把数据包在网络拓扑上的旅程可视化，能看清每一步的时序。
- **逐字节解码**：每个报文拆到字段与字节级，接近 Wireshark 的视图，建立「协议字段 ↔ 字节」的对应。
- **完整链路**：DNS → TCP 握手 → TLS 握手 → HTTP 请求/响应，再补 DHCP、ICMP、ARP、邮件协议、FTP、SSH。
- **教学深度**：涉及 SNI、ALPN、密码套件、后量子混合密钥交换（X25519MLKEM768）、SSH 版本协商等细节。
- **多语言与主题**：14 种语言，明暗主题，移动端适配。

## 访问与使用

**访问**：

```text
https://protocol-explorer-alpha.vercel.app/
```

大陆网络直连会超时，需要代理。

**建议学习顺序**（按一次上网的真实链路）：

1. DNS：域名 → IP
2. TCP：三次握手与可靠传输
3. TLS：证书、密钥交换、SNI/ALPN
4. HTTP/HTTPS：请求响应与版本差异
5. IP / ICMP / ARP / DHCP：底层寻址与配置
6. UDP / SSH / 邮件协议 / FTP：按需补充

**学习方法**：先看动画建立流程 → 回看逐字节解码 → 用自己的话复述 → 去 Wireshark 抓一次真实流量对照。开英文界面还能顺带练专业词汇。

## 适用场景与边界

**适合**：网络/后端/运维初学者建立协议直觉；面试或考试复习；团队网络培训找可视化素材。

**不适合**：需要抓自己流量的排障场景（它不能抓包）；需要权威规范细节的场合（应查 RFC）。

**注意**：项目处于 alpha，课程完整度与维护情况待观察；闭源意味着无法复用实现，只能参考思路。
