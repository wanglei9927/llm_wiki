# XFeed

> XFeed（https://xfeed.ai）是一个中文界面的网页应用，聚合 X（Twitter）上 AI 创作者的实测、教程与工具动态，按主题/类型/时间筛选，并提供入门学习路线与作者精选。

## 它是什么

面向「想看 AI 创作者每天在做什么」的内容发现站：把 X 上分散的 AI 实测、教程、工具、开源与免费福利汇总到一个可筛选的榜单里；外文摘要由 AI 翻译，完整内容跳回 X 原帖，好内容回到原作者。

## 主要功能

| 功能 | 说明 |
|---|---|
| 主题筛选 | 默认全部 / 设计师 / 自媒体 / 程序员 / 办公与新手 |
| 类型筛选 | 编程 / 图片 / 视频 / 办公 / 智能体 / 其他 |
| 时间筛选 | 近 24 小时 / 3 天 / 7 天 / 30 天 / 按月 |
| 排序 | 曝光最多 / 收藏最多 / 最新发布 |
| 隐藏官方 | 只看个人创作者 |
| 本周热门工具 | 按近 7 天提及作者数排序 |
| 入门专题 | 新手入门、个人网站、图生短视频、日常助手、整理资料 |
| AI 问答 | 围绕内容的提问检索 |

## 评价与注意

- **优点**：中文界面、AI 翻译摘要、以实操/教程/工具为主、尊重原创（回到原帖）、官方/个人可分离。
- **注意**：榜单依赖 JavaScript 渲染；外文摘要为 AI 翻译，可能与原意有出入，需回原帖核对；数据源仅限 X 平台。
