# DeskBox

> 免费开源的 Windows 10/11 桌面整理工具：用 WinUI 3 在桌面上加一层「原生质感格子」，文件格子由真实文件夹支撑，被视作 Stardock Fences 的现代开源替代

## 简介

DeskBox 解决的是 Windows 桌面「文件越堆越乱」的问题：它不替换资源管理器，而是在桌面上叠一层格子。你可以把文件拖进格子（实际是真实文件夹）、把已有文件夹映射成格子、用格子组合并多个文件夹，或让「桌面整理」按类别把散落文件收进对应格子。

除文件格子外，它还提供时光（日期/农历）、待办、随记、搜索、天气、音乐等附加格子，并支持 Mica/Acrylic 原生材质、托盘与全局快捷键唤起。

## 功能概览

- **文件格子**：真实文件夹支撑、图标/列表布局、手动/规则排序、密度与图标大小、50×50 起、单行/双行/隐藏文件名
- **格子组**：合并不改底层文件夹、标题/滚轮/Ctrl+Tab 切换、安全拆出
- **叠放**：自动归组、格子内展开或独立弹窗（自适应/3×3/5×5）
- **桌面整理**：先预览再移动、按类别新建或复用格子、失败原因逐项说明
- **自动整理**：等下载/解压/替换稳定后触发，等待时间实时～12 小时
- **附加能力**：时光、待办、随记、搜索、天气、音乐、QuickLook 预览、托盘与全局快捷键

## 评价

**优点**：

- 核心承诺克制：文件格子是真文件夹，不绑架用户数据；
- 原生质感好（Mica/Acrylic、WinUI 3），比多数 Electron 桌面工具轻；
- 工程化程度高：Native AOT、离线安装、校验与签名、CI；
- 开源 GPL-3.0，可自行编译审计。

**注意点**：

- 仅 Windows 10/11（x64/ARM64），macOS/Linux 用户用不了；
- 与 Fences 等商业工具功能有重叠，但生态/插件远不如；
- 会接管桌面布局，首次使用建议先小范围试；
- 「自动整理」移动文件前务必看清预览，避免误动重要文件。

## 不同素材中的观点

- **[来源: [[DeskBox 桌面整理工具]]]** README 明确把「文件格子」当核心、把时光/待办/搜索等当附加能力，这个定位比「全能桌面」更可信；对桌面长期混乱、又不想用收费 Fences 的 Windows 用户，是目前最值得试的开源方案之一。
