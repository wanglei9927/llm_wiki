# DeepTutor

> 港大数据智能实验室（HKUDS）开源的「终身个性化家教」：把聊天、测验、研究、掌握路径串成学习流，并记住你学到哪、哪里薄弱

## 简介

DeepTutor 想做的是「一个能陪你很久的 AI 家教」：你告诉它想学什么，它生成结构化学习路径；学习过程中聊天、出题测验、查资料、做研究都在同一个工作区里，并且有长期记忆，能根据你的薄弱点调整下一步。项目由港大 HKUDS 出品，MIT 风格的学术开源项目（Apache-2.0），有论文（arXiv:2604.26962）与 EduHub 技能社区。

## 核心能力

- **个性化学习路径**：输入主题 → 结构化路径 → 分阶段学习
- **长期记忆**：记录学到哪、薄弱点，后续辅导据此调整
- **多形态学习**：聊天问答、随堂测验、研究/查资料、掌握度评估
- **桌面端**：macOS（Apple Silicon/Intel）与 Windows x64 安装包
- **CLI / Agent 原生接口**：可脚本化、可被 Agent 调用
- **扩展**：EduHub 技能社区；Anki/日历导出、视频课程、知识库连接等

## 安装 / 使用

```bash
pip install -U "deeptutor[full]"   # Web 全量 + CLI
# 或裸装核心：pip install -U deeptutor
```

Docker 镜像（GHCR）可用于快速试用；桌面版从 Releases 下载。

## 评价

**优点**：

- 学术团队出品，有论文与持续迭代（周更级 release）；
- 「记忆 + 掌握路径」比一次性问答更接近真实家教；
- 开源、可本地/自托管，数据可控；
- 桌面端降低了非技术用户的上手门槛。

**注意点**：

- 需要配置模型 API Key，长期使用有 token 成本；
- 项目更新快，界面/配置可能变化，以官方文档为准；
- 中文界面与中文课程质量需实际体验验证。
