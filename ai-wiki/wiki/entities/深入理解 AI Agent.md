# 深入理解 AI Agent

> 李博杰所著《深入理解 AI Agent：设计原理与工程实践》，57,764★ 的开源书：用「Agent = LLM + 上下文 + 工具」一个公式串起 10 章，配 109 个可运行实验，正文/PDF/EPUB 全部开源

## 简介

这本书试图回答一个具体问题：**当模型能力趋同，Agent 的差距从哪里来？** 作者的答案是 Harness 工程——上下文、工具、记忆、评估、进化这些「模型之外」的部分。全书因此按「一个公式 + 十章递进」组织：先把 Agent 拆成 LLM、上下文、工具三块，再分别深入上下文工程、记忆与知识库、工具协议（MCP）、Coding Agent、交互扩展、评估、后训练、持续进化、多 Agent 协作。

它的另一大特点是**实验驱动**：109 个配套实验按章组织，支持 `uv` 锁定环境复现，也能只挑单章跑；不是「读完就忘」的理论书。

## 推荐阅读路径

- **只想建立概念**：第 1 章 + 第 2 章 + 学习建议（LEARNING.md）
- **做工程落地**：第 2、3、4、5 章优先，配合第 7 章评估
- **做模型/训练**：第 8、9 章
- **做多 Agent 系统**：第 10 章 + 第 6 章（交互扩展）
- **时间有限**：先看每章「一句话核心」与配套实验 README，再决定深读哪章

## 评价

**优点**：

- 公式清晰、结构递进，适合作为「AI Agent 知识地图」；
- 实验量大且可复现，理论能落到代码；
- 中文原版 + 多语言社区翻译，更新活跃（2.0 版已重排章节）；
- 开源免费（Apache-2.0），PDF/EPUB 离线可读。

**注意点**：

- 体量大（10 章 + 109 实验），不适合一次读完，建议按需查；
- 部分实验需要模型 Key 或 GPU（第 8 章训练相关），成本需预估；
- 2.0 版章节有重排，旧版 PDF 与新版目录不一致，以最新版为准。
