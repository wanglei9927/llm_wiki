## 核心观点

1. **动机：人的注意力是最大瓶颈**。引 DeepSeek《Super-agent设计探索》开篇："一个人通常只能同时跟进3到5个活跃的会话，单任务的上限取决于模型能力，多任务的上限取决于人的注意力"。类比朱元璋废丞相后 8 天处理 1660 件奏札（"朕一人处此多务，岂能一一周遍"）——用 Agent 的时代人人都是"自己的皇帝"，解法是"领导力思维"：把任务起点从人身上拿掉，用信号触发 Agent，而不是等命令。

2. **自动化中台（最核心模块）**：小型独立服务（轻量服务器+数据库），所有事件（定时轮询、Webhook、消息、邮件、告警）先入中台，统一格式（来源/类型/对象/一句话摘要/回链，如 `feedback.new #12`），规则写在 `rules.json`（事件 → Agent + skill + 指令 + 并发上限 + "只在需要决策时上报"）。中台五大好处：①新事件只加一条规则；②换模型改一行；③统一去重；④消息单一出口（飞书 AI 助理"小卡"）；⑤全量数据沉淀可回溯。

3. **内网穿透问题的反向解法**：Mac 都在家/办公室内网，Webhook 推不进来——每台 Mac 跑一个"接单程序"长轮询中台（一次最长等 50 秒），不用暴露公网，速度接近实时。

4. **多模型按特长调度（省钱省 Token）**：200 刀 Claude 会员 3 天能用完近 90%。分工：Claude Opus 5.5 主力开发（复杂、需主观能动性的活）；GPT-6.1 Sol 管运维（告警、日报、到期复查、修 BUG）；GPT-6.1 Terra 干浏览器/电脑操控（操控登录好账号的 Chrome，抓没有接口的数据）。原则："做决策和管理的模型必须智力最强，不能用笨的指挥聪明的"。全部跑在本地两台 Mac Mini（M5 Pro 日常 + M4 跑自动化任务），不上云——登录态、权限、国内服务可访问性（微信云浏览器直接崩）决定了本地更优。

5. **每个自动化任务配一个专属 Skill**：Skill = 沉淀给 Agent 用的 SOP（规则+参考+脚本），例：每周日"大扫除"任务删屎山（重复实现、个案补丁、停用未拆净、流水账文档）。好处：改任务详情只改 Skill，与 Agent 执行逻辑解耦。

6. **自建 CI 中台（五步流水线）**：GitHub CI 3000 分钟/月额度扛不住 AIHOT 一天二三十个 PR（10 月近 1000 个，超额费每月 50 刀+），于是在 M4 Mac Mini 自建。Agent 干到提 PR 就结束、自己不能上线，之后五步：**审查**（Codex 只读/断网/读不到密钥，只报会出错的、不报风格，最多审 3 次防无限挑错——学自 Anthropic《How the Claude Code team does code review》）→ **检查**（类型检查/全测试/构建/"数据库只能加不能改"硬规矩，每任务开全新虚拟机，跑完即删，Agent 代码从不直接跑在 Mac 本机）→ **合并**（GitHub 规则写死：没审过没检查过合不进主干）→ **发布**（M4 专机）→ **核实**（确认线上版本真包含改动才写回 GitHub）。中位数两三分钟全流程，无需人管。

7. **"批奏折"人机决策边界**：最像"票拟+批红"——飞书卡片由 Agent 写好建议，人只点击。曾一天被推几十条卡片踩过坑，现在**必须先问人的仅限**：删数据、停服、花钱、对外发消息、改产品方向、新建/轮换密钥、修改权限，其余 Agent 全权做完上线。配套两份决定文件：「卡兹克定的事」（亲口决定+原话+日期，Agent 不会问第二遍）、「定了不做的事」（拒绝过的，Agent 直接照答不再烦人）。例外：用户反馈完全不交给 Agent 筛选，每条亲自看、亲自转给 Agent 执行并回信——"最后的一种仪式感"。

## 实操内容保留

**关键架构决策（可复用）**：

- 事件统一消息格式：从哪来、什么类型、对象是谁、一句话摘要、回到原处的链接
- `rules.json` 规则要素：事件类型 → 指定机器上的指定 Agent + 代码目录 + 指定 skill + 一句指令（"按 skill 里对应的那一节办"）+ 并发限制（每条意见单独开一轮、同一条只跑一轮、最多 3 条并行）+ 上报策略（只在需要决策时）
- 内网接单程序：长轮询（单次最长等 50 秒），替代公网 webhook 回源
- Codex 审查三条规矩：只读不能改、连不了网、读不到任何密钥
- 审查轮次上限 3 次（Anthropic Claude Code 团队同款纪律）
- 必须人工决策清单：删数据/停服/花钱/对外发消息/改方向/密钥/权限
- 决定文件两份：「XX定的事」+「定了不做的事」

**审查效果数据**：最近两周 4 个项目审 298 个 PR，Codex 报 333 条问题，306 条合并前修掉，最严重档 51 条；单次审查中位数 2 分多钟，占任务 Token 5%–15%。
