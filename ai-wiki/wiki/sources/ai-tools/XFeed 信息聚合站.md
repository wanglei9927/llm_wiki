# XFeed：追踪 X 平台 AI 创作者动态的聚合站

> 官网 https://xfeed.ai —— 一个中文界面的网页应用，聚合 X（Twitter）上 AI 创作者的实测、教程与工具动态，按主题/类型/时间筛选，外文摘要 AI 翻译，好内容回到原帖。

## 核心功能

1. **多维度筛选**：主题（默认全部 / 设计师 / 自媒体 / 程序员 / 办公与新手）× 类型（编程 / 图片 / 视频 / 办公 / 智能体 / 其他）× 时间（近 24 小时 / 3 天 / 7 天 / 30 天 / 按月）。
2. **三种排序**：曝光最多 / 收藏最多 / 最新发布。
3. **隐藏官方**：按已收录官方账号名单过滤，只留个人创作者内容，避开官方公告噪音。
4. **本周热门工具**：按「近 7 天提及的不同作者数」排序，看大家正在用什么。
5. **作者精选**：推荐持续分享具体做法的实战创作者，用于扩充关注列表。
6. **入门专题/学习路线**：新手入门、做个人网站、图生短视频、搭日常助手、整理资料——每条 10 分钟就能跑通的实战路线。
7. **AI 问答**：围绕创作者内容做提问检索。

## 核心观点

- **「好内容，回到原作者那里」**：站内是聚合 + AI 翻译摘要，完整内容跳回 X 原帖，尊重原创。
- **以「实测 / 教程 / 工具」为主**，不是新闻或八卦，适合当作 AI 实操灵感的每日来源。
- **官方与个人分离**：可一键只看个人创作者，减少官方号的营销/公告内容。

## 实操记录

- 首页是 JS 渲染的榜单，静态抓取只能拿到导航与栏目文案；具体榜单内容需浏览器渲染或站内接口。
- 定位上是 Horizon 之外、面向「AI 创作者实操」的补充信源（尤其中文用户），可配合每日浏览。
