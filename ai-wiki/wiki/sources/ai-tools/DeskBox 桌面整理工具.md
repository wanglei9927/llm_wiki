# DeskBox：开源 Windows 桌面整理工具

> 用 WinUI 3 给 Windows 桌面加一层「原生质感格子」的免费开源工具，被视作 Stardock Fences 的现代开源替代；文件格子由真实文件夹支撑，另有待办、随记、搜索、天气、音乐等附加格子

## 核心观点

1. **定位清晰**：不是「替换资源管理器」，而是在原生桌面上加一层轻量格子；文件格子由**真实文件夹**支撑，不改变文件原本位置与使用方式。

2. **Fences 的开源替代**：Stardock Fences 长期收费且更新缓慢，DeskBox 用 WinUI 3 + Mica/Acrylic 做出原生质感，并把「文件格子」作为核心承诺，其余（时光、待办、随记、搜索、天气、音乐）是附加能力。

3. **工程细节扎实**：Native AOT 构建、内置私有 Windows App Runtime、SHA256 校验、SignPath 代码签名、CI 徽章；拖放支持 Windows 原生复制/移动判断、跨磁盘与修饰键、逐项进度与冲突保护。

4. **收纳逻辑完整**：格子组（合并/切换/拆出）、叠放（自动归组、3×3/5×5 弹窗、跟随缩放）、桌面整理（先预览再移动，按类别新建或复用格子）、自动整理（等下载/解压稳定后再动）。

5. **本地优先 + 多语言**：13 种语言、资源键一致；数据全本地，符合对隐私敏感用户的预期。

## 实操内容保留

### 下载与安装

- x64：`DeskBox_Setup_1.5.9_x64.exe`（Intel/AMD）
- ARM64：`DeskBox_Setup_1.5.9_arm64.exe`（骁龙、Surface Pro X）
- 均为 Full Native AOT + 内置私有 Windows App Runtime 2.5.1，可离线安装；每个包附 `.sha256` 校验文件
- 默认安装到当前用户目录（免管理员）

### 核心功能清单

| 模块 | 能力 |
|---|---|
| 文件格子 | 新建/映射真实文件夹、图标/列表布局、排序（手动/规则）、密度与图标大小、单行/双行/隐藏文件名、50×50 起 |
| 格子组 | 合并不改底层文件夹、标题/滚轮/Ctrl+Tab 切换、安全拆出/解散 |
| 叠放 | 总开关 + 自动归组、格子内展开或独立弹窗（自适应/3×3/5×5）、共用缩放 |
| 拖放 | 拖入/拖出、复制剪切粘贴、重命名删除、在资源管理器显示、原生拖放图像、跨盘与修饰键 |
| 桌面整理 | 先按类别预览、新建或复用格子、按访问拒绝/占用/已变更/目标不可用分别说明保留原因 |
| 自动整理 | 下载/解压/同路径替换稳定后触发，停留等待 实时～12 小时可配 |
| 附加格子 | 时光（日期/农历）、待办、随记、搜索、天气、音乐 |
| 其他 | QuickLook 空格预览、托盘/全局快捷键唤起、Mica/Acrylic 材质 |
